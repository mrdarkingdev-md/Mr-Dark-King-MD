# Mr Dark King MD - WhatsApp Bot

A WhatsApp bot built with WhatsApp.js and Node.js.

## Features
- WhatsApp integration
- Telegram integration
- Custom commands (menu, owner)

## Installation

```bash
npm install
```

## Usage

```bash
npm start
```
